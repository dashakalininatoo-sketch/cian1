# Прототип мобильной главной Циана

Кликабельный концепт для задачи [«Главная на мобильных»](../tasks/home-mobile/task.md). Показывает первый экран и ленту, пять направлений поиска, рекомендации, рекламное место и два состояния пользователя.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite. Для проверки сборки: `npm run build`; для просмотра готовой сборки: `npm run preview`.

## Как пройти прототип

- Переключатель «Новый / Вернулся» в верхней части главной меняет демонстрационное состояние. У возвращающегося пользователя появляются сохранённые поиски.
- Поиск открывает экран ввода с выбором направления. Пять плиток направлений открывают выдачу. Карточки рекомендаций и выдачи открывают страницу объекта.
- Рекламный блок обозначен и открывает отдельную страницу партнёрского проекта. На внутренних экранах стрелка возвращает на главную.

## Допущения

Город — Москва. Адреса, цены, объявления, контакты и сохранённые поиски демонстрационные. Данные и иллюстрации хранятся локально; сервер и внешние API не требуются. Изображения объектов — стилизованные SVG-иллюстрации для концепта, а не фотографии реальных квартир. Поиск фильтрует только подготовленные демонстрационные варианты и показывает пустое состояние, если совпадений нет.
