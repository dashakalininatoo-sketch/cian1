# cian1 · Учебный репозиторий

Приватный учебный репозиторий для практики «Три репозитория». В исходном состоянии здесь намеренно не было кода, дизайн-системы и правил: агент собирает прототип с нуля. Так видно, что даёт модель сама по себе. Сравниваем с `cian2` — стек и UI-kit Циана — и `cian3` — полное рабочее место дизайнера.

- [tasks/](tasks/README.md) — карточки задач практики.
- [team/](team/README.md) — участники: у каждого свой файл `team/<github-логин>.md`.

## Прототип мобильной главной

В ветке `dyachkovp/home-mobile` находится кликабельный концепт для задачи «Главная на мобильных»: два состояния пользователя, поиск, пять направлений, рекомендации, реклама и основные переходы. Инструкции по запуску и допущения — в [docs/prototype.md](docs/prototype.md).

```bash
npm install
npm run dev
```

Свою работу ведите в ветке `<github-логин>/<задача>` и показывайте пул-реквестом.
